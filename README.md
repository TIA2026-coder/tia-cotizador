# Cotizador de Herrería · TIA

App para cotizar trabajos de herrería (material, consumibles, viajes y mano de obra), con PDF para el cliente, lista de material y Excel del mes.

- `generica.html`: versión para cualquier taller (se activa con código de TIA).
- `robles.html`: versión personalizada de Herrería Robles.
